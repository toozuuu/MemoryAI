# `memoryai-mcp` Skill

Model Context Protocol (MCP) tool integration and calling standards.

## Supported Tools
- `memory_auto_context`
- `memory_recall`
- `memory_remember`
- `memory_handoff_create`
- `memory_handoff_get`
- `memory_share`
- `memory_embeddings_status`
- `memory_search`
- `memory_update`
- `memory_forget`
- `memory_status`

## Transport
- Stdio-based JSON-RPC protocol compliant with the official MCP specification.
